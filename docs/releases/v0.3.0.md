# v0.3.0 — Assisted applications with manual submission

## Delivered

- Experimental **Lever hosted-form contact autofill**, global and EU: name, email, optional phone and current company.
- A bilingual consent preview with the exact destination, contact values and selected approved resume; authorization expires after ten minutes and is usable once.
- A visible, ephemeral Chromium window. Requests are paused during filling/review, with a separate confirmation to take manual control of that same window.
- Manual PDF attachment, employer questions, legal consents, CAPTCHA and submission. The app never clicks Submit, uploads documents or guesses restricted answers.
- Durable attempt records, input-change checks, one unresolved attempt per application, explicit outcome reconciliation and no automatic retries after uncertain results.
- Session close, restart and restore invalidate unused grants and require review of interrupted attempts. Exports include attempt history without browser sessions.
- EN/ES guidance, mobile consent layout, error/recovery messages, and an operating guide.
- The first release archive containing the noncommercial license, personal job-search permission and community contribution files.

These checks do not establish a completed employer submission E2E.

## Limits

The user workflow requires a local graphical desktop. macOS is the verified platform; CI can exercise headless components on Linux without validating a Linux desktop installation. Custom employer-hosted forms, embedded forms, other ATS platforms, automatic resume uploads, custom-answer autofill, auto-submit, AI and email remain outside this release.

Hosted forms may change. Unknown forms require manual handling. Browser traffic is restricted to the selected Lever origin and hCaptcha; unsupported resources may fail and a manual reload can discard filled values. No browser request filter is a general OS/network sandbox. A completed outcome is the user's attestation, not independent employer verification.

The repository remains private. The four dependency alerts and public-repository controls already documented in [publication preparation](../operations/public-repository.md) remain deferred at the owner's request. Do not read this release as clearance to make the repository public.

## Upgrade and use

Preserve a private backup, stop the previous app, update the checkout, and start it. The launcher applies the additive `0004_assisted_applications` migration. Existing profile facts, job records and documents remain in place. Operational backups are not encrypted.

```sh
pnpm run backup
pnpm run stop
git pull --ff-only
pnpm install --frozen-lockfile
pnpm start
```

Start in **Applications → Assisted application** with a Lever URL and a current approved resume.
