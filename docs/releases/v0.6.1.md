# Career Stack v0.6.1 — Estados claros y revisión continua / Clear status and review continuity

## Español

- Confirmar una empresa indica que está lista para consultar; el panel de búsqueda muestra por separado si la automatización está activa o pausada. Desactivar una empresa también se distingue de pausar toda la búsqueda.
- Nuevas por revisar avisa cuando cambian los resultados, sin reordenar las tarjetas mientras lees. Actualizar resultados conserva los filtros; al volver a la pestaña se comprueban las novedades.
- Revisar la última oferta de una página vuelve a una página válida y conserva búsqueda, disponibilidad y lista seleccionada.
- Marcar como revisada muestra confirmación y un enlace para continuar, con foco de teclado. Un error permite reintentar; el éxito limpia el error anterior.
- Un fallo al cargar la búsqueda muestra error y reintento, sin un mensaje de carga permanente. Si falla una actualización, el estado aparece como Sin actualizar; se conserva la información anterior y se bloquean cambios hasta recuperar el estado.
- Las consultas interrumpidas o fallidas no prometen reintentos mientras la programación está pausada. Los errores de una acción no desaparecen por una consulta automática de estado posterior.
- Español e inglés, con cobertura de escritorio y pantallas de 390 y 320 px.

### Actualización y límites

Detén la app, actualiza el código y ejecuta `pnpm start`. Esta corrección no añade migraciones ni cambia tus datos o la preferencia de automatización. El servicio local debe seguir encendido para consultar empresas. El envío de solicitudes sigue siendo manual.

## English

- Company confirmation and disabling are distinguished from the global automatic-search switch.
- The new-jobs inbox detects background changes and offers an explicit update, preserving filters and leaving displayed cards in place until requested.
- Reviewing the last item on a page recovers to a valid page without dropping search, availability or list filters.
- Reviewed jobs have a success message and keyboard continuation; failed reviews remain retryable and clear their error on success.
- Initial errors stop loading feedback. Failed status refreshes label cached information Out of date and disable changes until recovery; polling never clears an action error.
- Interrupted/failed checks no longer promise retries while paused. The interface remains bilingual and responsive.

Stop the app, update the code and run `pnpm start`. No migration or changes to saved data or automation preference are included. Local-service and manual-submission limits remain unchanged.
