# v0.9.0 — Optional assistance with Codex

## What changes

- Connect an existing official Codex account, review the masked identity and explicitly choose which text to share. Usage is shown only when the official interface reports it.
- Describe the job you want and review editable search criteria; unsupported restrictions stay visible.
- Read job summaries with references to the posting and selected confirmed experience.
- Review resume wording, preserve originals and approve the exact generated PDF. AI suggestions do not change the profile.
- Save an answer as a new, unapproved version with its question, country, scope and expiry. Personal and legal decisions remain yours.
- Optionally analyze future jobs from selected searches, with a daily limit, pause and manual priority. Ordinary searches work without AI.
- Recover accepted tasks and suggestions after closing a tab or restarting, without silently retrying uncertain inference. Restore pauses automation and revokes assistant grants.

The interface remains English/Spanish and keeps assistant help contextual and optional. [Walkthrough, data sharing and limits](../operations/assistant.md).

## Update

1. Create and verify an independent backup.
2. Stop the service, update the checkout and run `pnpm install --frozen-lockfile`.
3. Start normally with `pnpm start`. Additive migration **0010** retains existing profile facts, answers, searches and PDFs.
4. Continue ordinary searches, or connect Codex from **Profile and tools → Settings and privacy → Assistant**. Nothing is connected or authorized automatically by the upgrade.

Downgrading the binary over the migrated database is not a rollback. Restore a verified older backup into a separate destination. The existing local workspace was not used as a test fixture.

## Support and verification limits

- Native AI execution: **macOS and Codex CLI 0.160.0**, using ChatGPT plan authentication. The adapter rejects other versions. Linux/Windows native AI is not certified; build checks do not establish equivalent isolation.
- No paid API fallback, new provider integration, whole-web search or new unattended submission capability. Claude is deferred.
- Four explicitly authorized tasks used entirely fictional data and passed their contracts. They reported **17,537 input / 803 output tokens**; these are not a monetary estimate or percentage of plan quota. The authorization was fully used; subsequent checks used mocks.
- Native isolation and cancellation used the actual CLI with a local mock server and external network denied. New-account login and cancellation during real account-backed inference were not exercised.
- Model suggestions can be wrong. Deterministic source validation, editable review and exact-PDF approval do not establish quality for every future job.
- Browser review uses fictional fixtures, backend integration uses disposable databases, and PDF validation uses real rendering. There was no formative study with new users or an actual screen-reader session. See the [detailed verification record](v0.9.0-validation.md).
