# v0.9.2 — Clearer job search and contextual AI

## Changes

Search creation now shows one method at a time: a natural-language request to Codex or manual filters. Drafts survive switching methods and navigating away. The account can be inspected and connected inside the search, without leaving the request behind.

Automatic-search status is compact; portal details and automatic-summary guidance are available on demand. Similar search names include distinguishing context. Each job has its own summary action and reports local saved/in-progress summary state in the current language. Opening that action focuses the section after the page finishes loading and displays recovered assistance without starting another task. A saved summary is not a guarantee of freshness: currentness is checked when it is opened.

Automatic summaries retain explicit consent. A guided entry lets people choose a job, request and review a first summary, then choose searches, profile data (optional) and a daily quota before authorizing future summaries. Connecting alone does not start inference.

Linked CVs show approval state; pending CVs prioritize review. Account refresh and portal problems use clearer ES/EN copy. The Himalayas reader accepts seconds, milliseconds and ISO timestamps, invalidating old reader-cache entries while preserving shared host rate limits and budgets.

## Upgrade

Save a backup, stop Career Stack, update the checkout and run `pnpm install --frozen-lockfile`, then `pnpm start`. Use Node 24 and the pinned pnpm 11.10.0. No migration is added after 0010. Existing profiles, searches, documents, connections and permissions remain in place.

## Verification

Release checks use disposable databases, private ports and isolated production dashboard builds. Synthetic assistant responses exercise consent and recovery without using a real provider account. Publication requires passing local checks and GitHub CI on the release commit.

- Search/API regressions, including timestamp formats, query-cache cooldowns and per-job/per-language summary states.
- Assistant unit and integration checks, UI logic, types and lint.
- Isolated search and assistant browser suites: ES/EN, keyboard, mobile and desktop, draft preservation, exact-job focus, inline connection and automatic-summary guidance.
- Search performance probe with 10,000 fictional jobs and 20 searches; this is a local benchmark, not a production throughput guarantee.

## Limits

No additional account-backed Codex tasks are used for this release. Native Codex support remains macOS with the supported CLI and ChatGPT session; Claude remains deferred. Tests do not certify every model response or replace usability sessions with new participants. Automatic summaries apply to new offers after explicit activation; they do not submit applications. Existing employer submission limits still apply.
