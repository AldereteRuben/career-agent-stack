# v0.10.0 — From job discovery to an application you can review

This release brings together the work merged since v0.9.2: stronger resume import, broader job discovery, evidence-based matching and application materials, better follow-up tracking, safer recovery, and a more compact interface.

## Highlights

- Import resume facts with optional Codex assistance. Imported details remain suggestions until reviewed and approved.
- Search an additional bounded, read-only Adzuna source; import job links and review availability and salary information.
- See clearer job-fit evidence, unknown requirements and skill-gap summaries, and provide explicit match feedback.
- Create and revise offer-specific resumes and cover letters from approved profile facts. Review evidence and exact PDFs before approval, download or export.
- Track contacts, imported application email, follow-up drafts, outcome metrics and timeline events alongside application stage history.
- Restore backups into an isolated copy before choosing whether to open that workspace. Application document revisions are included in backups.
- Optionally use local Ollama assistance or desktop job notifications. Both are opt-in.
- Reduce dashboard scrolling and align controls and detail panels across the interface.

## Upgrade

Make and verify a backup, stop Career Stack, update the checkout, then run `pnpm install --frozen-lockfile` and `pnpm start`. The migration sequence now includes migrations 0011–0019; startup applies pending migrations while retaining the existing workspace. Use Node.js 24.x and pnpm 11.10.0.

## Verification

Release candidate checks are recorded here after they finish. The release PR must pass the complete GitHub Actions CI workflow before merge and publication. Browser and integration tests must use disposable databases and isolated builds, never the real workspace.

## Limits

Job discovery depends on the configured sources, their coverage and their request limits. Matching describes evidence coverage; it is not a hiring probability or an ATS score. Codex remains an optional, consent-based integration supported on macOS with CLI 0.160.0 or 0.163.0 and ChatGPT plan authentication. Ollama is local and opt-in. Application assistance does not submit applications unattended; supported simple forms still require a per-application authorization, and CAPTCHA, legal declarations, unsupported questions or unrecognized forms require manual completion. Platform verification limitations remain in [local setup](../operations/local-setup.md).

## Español

Esta versión reúne las mejoras desde la v0.9.2: importación más útil del CV, más fuentes de ofertas, encaje explicado con evidencia y materiales de candidatura que puedes revisar. También añade contactos, importación de mensajes, borradores de seguimiento, métricas y eventos en la cronología. La restauración permite comprobar una copia aislada antes de abrirla; las revisiones de documentos se incluyen en las copias de seguridad. Ollama local y las notificaciones de escritorio son opcionales. La interfaz reduce desplazamientos y unifica sus controles.

Para actualizar, crea y verifica una copia, detén Career Stack, actualiza el repositorio y ejecuta `pnpm install --frozen-lockfile` y `pnpm start`. Se aplican las migraciones pendientes 0011–0019 sin reemplazar el espacio existente. Usa Node.js 24.x y pnpm 11.10.0.

La búsqueda depende de las fuentes y sus límites. El encaje representa cobertura de evidencia; no predice contrataciones ni es una puntuación ATS. Codex sigue siendo opcional y requiere consentimiento; Ollama procesa localmente. La app no envía candidaturas sin supervisión: los formularios sencillos requieren autorización individual, y CAPTCHA, declaraciones legales, preguntas no compatibles y formularios desconocidos requieren intervención manual. Las limitaciones de compatibilidad se detallan en [la guía de instalación](../operations/local-setup.md).
