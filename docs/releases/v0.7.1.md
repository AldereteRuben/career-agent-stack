# v0.7.1 Simpler search and application flow

This release closes the usability review of the search → profile → resume → application journey. It preserves explicit review and submission authorization.

## Review checklist

- [x] Scheduled search results and prepared applications appear without a manual reload; background updates preserve focus, drafts and action errors.
- [x] Search validation appears next to the form and focuses the missing criterion. Source failures do not suggest changing keywords or imply there are no jobs.
- [x] Applications without a resume offer the same automatic preparation action as job details and the profile.
- [x] An unsent application does not say it is awaiting an employer response. Manual state corrections are separate from routine progress.
- [x] Unsupported job links offer a clear manual continuation instead of Lever instructions; closed applications do not invite another submission.
- [x] Preparation and submission activity use complete Spanish and English labels.
- [x] Job details use compact metadata and one review strip instead of stacked notices; actions fit narrow screens.
- [x] Profile, resume, assisted-form and application links retain the original search context.
- [x] Automatic preparation feedback receives focus when details are missing; current user-selected documents remain protected.
- [x] Saved search cards, search-first onboarding, immediate experience confirmation, readable imported descriptions and document navigation from the earlier review are included.
- [x] Failed saves in profile, documents and applications bring the error into view without discarding entered data.
- [x] Distinct component keys preserve independent preparation and assisted-form state.
- [ ] Release gate: isolated end-to-end scenarios, production build and GitHub CI must all pass before main and the tag are updated.

## Verification

Implemented and checked with lint, workspace TypeScript and E2E TypeScript validation. The 173 automated checks pass: domain (31), sources (19), discovery (13), saved searches (21), backup archive (30), backup API (6), restore/migration (17), preparation (7), assisted routes and synthetic browser (29).

The isolated E2E suite includes 31 scenarios, including new background-refresh/error-recovery and bilingual application-continuation regressions. Its final result and the GitHub CI evidence are recorded when the release gate completes. Test data and screenshots remain in the ignored local output directory.

## Existing limits

Sources remain Remotive and Arbeitnow plus explicitly followed company boards. Matching and resume selection use deterministic evidence, not AI. The local service must remain on for scheduled work. Unsupported application forms require manual completion. Backup restoration still uses the terminal. No unattended real-employer submission is claimed.
