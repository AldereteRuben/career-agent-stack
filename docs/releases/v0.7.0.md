# v0.7.0 — Search, prepare, apply

## Delivered scope

1. **Find jobs automatically:** role/company queries, optional location/work-mode filters, source attribution, persistent results and 6/12/24-hour schedules. Sources: Remotive and Arbeitnow. No API key or employer-board setup is needed for those feeds.
2. **Prepare applications automatically:** opt in per query, or prepare a single saved job. Approved profile facts are selected by deterministic text overlap; relevant approved answers are suggested. Missing profile details lead to an actionable review item. PDFs remain pending review and are never approved by the worker.
3. **Experimental authorized Lever submission:** the visible browser checks a narrow form shape, the approved PDF and reviewed contact values. A distinct one-use authorization permits one upload/submission. Success requires both a successful response and a new visible receipt. Unknown outcomes are reconciled before another attempt. Unsupported forms retain the manual path.

The implementation follows [the three-task plan](v0.7.0-plan.md). The third task does not establish unattended real-employer sending.

## Data and upgrade behavior

Migration 0008 adds saved queries, public feed caches, source identities and query matches. Existing profile, job, document and application records remain intact. Repeated preparation preserves old files and the existing application cycle; approved documents and submitted, uncertain or closed applications are protected.

JSON exports include the new workspace data with automation disabled. Backup restoration pauses saved queries and automatic preparation, as well as existing company discovery. Neither restart nor restore resumes an application submission.

## Coverage and operational limits

- The local API and computer must stay on for scheduled checks. Closing the browser is fine; there is no cloud scheduler or installed OS background service.
- Remotive and Arbeitnow determine available jobs. This is not LinkedIn search or whole-market coverage. Source failures preserve previous jobs and indicate reduced freshness/coverage. A missing listing in a bounded feed never proves the vacancy closed.
- Remotive public jobs are delayed by 24 hours; each provider is fetched at most every six hours. New searches can reuse that cache. Read-only samples inspected on 2026-10-03 contained 16 Remotive jobs and 325 Arbeitnow first-page entries across its .com/.co.uk/.fr/.ch link hosts; these are sample counts, not availability guarantees.
- Matching uses text evidence, not AI, and is not a hiring probability. Preparation does not invent answers or qualifications. Review the PDF and missing details before use.
- Aggregator links are retained with source attribution. A direct supported employer form URL is needed for Lever assistance; a search result is not automatically a supported submission target.
- Public GET-only structural inspection found CAPTCHA/custom controls on [Lever demo](https://jobs.lever.co/leverdemo/681fbc53-1e34-4a46-8677-3a78118674eb/apply) and [Lever EU](https://jobs.eu.lever.co/lever/065f4538-7347-4207-909f-4ea68f63b4af/apply). Both remain manual-only. The demo also uses an asynchronous resume parsing upload. Synthetic tests prove the bounded adapter behavior, not a real employer submission.
- Legal declarations, additional questions, CAPTCHA, authentication and unsupported upload flows need manual handling. No email integration, autonomous retry of uncertain sends or arbitrary ATS support is added.
- Existing installation limits remain: Unix-based launcher, unverified complete Windows/Linux setup, and terminal-based backup restore. The repository stays private.
