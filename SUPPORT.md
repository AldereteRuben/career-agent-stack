# Getting help / Cómo pedir ayuda

Career Agent Stack is maintained by volunteers in their spare time. There is no paid support and no response-time guarantee, but every report is read.

| You want to… | Go to |
| --- | --- |
| Ask a question, share an idea or get installation help | [Discussions](https://github.com/AldereteRuben/career-agent-stack/discussions) |
| Report a reproducible problem | [Bug report](https://github.com/AldereteRuben/career-agent-stack/issues/new?template=bug_report.yml) |
| Propose a concrete improvement or translation | [Improvement](https://github.com/AldereteRuben/career-agent-stack/issues/new?template=feature_request.yml) |
| Report a vulnerability | [Security policy](SECURITY.md), never a public issue |
| Ask privately for a way to report something sensitive | [Private channel request](https://github.com/AldereteRuben/career-agent-stack/issues/new?template=private_channel.yml), with no details |
| Report abusive behavior | [Code of conduct](CODE_OF_CONDUCT.md) |

Before asking, check the [README](README.md), the [local setup and recovery guide](docs/operations/local-setup.md) and existing issues and discussions. `pnpm run doctor` explains most installation problems.

Use fictional data in everything you share. Never post CVs, `.env` files, sign-in tokens, backups, exports or unredacted logs and screenshots.

## Español

Career Agent Stack lo mantienen personas voluntarias en su tiempo libre. No hay soporte de pago ni plazos de respuesta garantizados, pero todos los reportes se leen.

| Quieres… | Ve a |
| --- | --- |
| Hacer una pregunta, compartir una idea o pedir ayuda con la instalación | [Discussions](https://github.com/AldereteRuben/career-agent-stack/discussions) |
| Reportar un problema que se puede reproducir | [Reportar un error](https://github.com/AldereteRuben/career-agent-stack/issues/new?template=bug_report.yml) |
| Proponer una mejora concreta o una traducción | [Proponer una mejora](https://github.com/AldereteRuben/career-agent-stack/issues/new?template=feature_request.yml) |
| Reportar una vulnerabilidad | [Política de seguridad](SECURITY.md), nunca un issue público |
| Pedir en privado una vía para reportar algo delicado | [Pedir un canal privado](https://github.com/AldereteRuben/career-agent-stack/issues/new?template=private_channel.yml), sin detalles |
| Reportar un comportamiento abusivo | [Código de conducta](CODE_OF_CONDUCT.es.md) |

Antes de preguntar, revisa el [README en español](README.es.md), la [guía de instalación y recuperación](docs/operations/local-setup.md) y los issues y conversaciones que ya existen. `pnpm run doctor` explica la mayoría de los problemas de instalación.

Usa datos ficticios en todo lo que compartas. Nunca publiques CVs, archivos `.env`, tokens de acceso, copias de seguridad, exportaciones ni registros o capturas sin censurar.
